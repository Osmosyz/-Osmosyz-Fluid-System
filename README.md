# (Osmosyz) Fluid System

**Versión:** 1.0  
**Compatibilidad:** Android 10 a 15  
**Dispositivo de referencia:** Redmi Note 8 (Ginkgo)  
**ROM base recomendada:** Evolution X  
**Kernel probado:** Ryzen (custom)

## Descripción

(Osmosyz) Fluid System es un módulo avanzado diseñado para mejorar el rendimiento general del sistema sin sacrificar recursos. Está optimizado para ofrecer mayor fluidez, liberar memoria RAM, evitar calentamiento durante la carga y mantener la experiencia fluida incluso durante sesiones de juego.

## Características

- Libera automáticamente hasta 2 GB de RAM.
- Reduce y congela tareas en segundo plano innecesarias.
- Acelera animaciones para mejorar la sensación de fluidez.
- Previene el sobrecalentamiento cuando el dispositivo está cargando.
- Compatible con juegos sin afectar su rendimiento ni latencia.
- Incluye sistema de aviso cuando hay nuevas versiones disponibles.
- Totalmente compatible con KernelSU y Magisk.
- Registro de logs en `/sdcard/Osmosyz/`.
- Al finalizar la instalación, abre automáticamente el canal de soporte: [@CanalOsmosyz](https://t.me/CanalOsmosyz).

## Notas

Este módulo fue creado para usuarios que desean aprovechar al máximo el rendimiento de sus dispositivos sin comprometer la estabilidad del sistema. Ideal para ROMs personalizadas, teléfonos con poca RAM y kernels modificados.
